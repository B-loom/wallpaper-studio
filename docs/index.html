What it doesCe qu'il fait

A real desktop application, not a browser in a window. Une vraie application de bureau, pas un navigateur dans une fenêtre.

Every formatTous les formats

MP4, MKV, WEBM, MOV, AVI through libVLC. GIF, APNG and animated WEBP. JPG, PNG, WEBP, TIFF. Plus HTML/CSS/JS wallpapers run in a sandbox. MP4, MKV, WEBM, MOV, AVI via libVLC. GIF, APNG et WEBP animé. JPG, PNG, WEBP, TIFF. Et des fonds HTML/CSS/JS exécutés dans un bac à sable.

Day / night schedulingProgrammation jour / nuit

Rules by hour, by weekday, per display. Night ranges that cross midnight work properly, and a change missed during sleep is applied on wake-up. Des règles par heure, par jour, par écran. Les plages qui traversent minuit fonctionnent, et une transition manquée pendant la veille est rattrapée au réveil.

Multiple displaysPlusieurs écrans

A different wallpaper per display, the same one everywhere, or one panoramic image spread across them. Settings survive unplugging a monitor. Un fond par écran, le même partout, ou une image panoramique répartie. Les réglages survivent au débranchement d'un écran.

Light on resourcesÉconome en ressources

7 MB of memory and 0 % CPU once the window is closed. The interface is freed, and the video player unloaded when no video is on screen. 7 Mo de mémoire et 0 % de processeur une fois la fenêtre fermée. L'interface est libérée, et le lecteur vidéo déchargé sans vidéo à l'écran.

Brightness, contrast, saturation, hue, blur, rotation, mirrors — with saved presets. Eight particle effects: rain, snow, stars, fog, glows, waves. Luminosité, contraste, saturation, teinte, flou, rotation, miroirs — avec des presets. Huit effets de particules : pluie, neige, étoiles, brouillard, lueurs, ondes.

Import de fichiers ou de dossiers, glisser-déposer. Tags, collections, favoris, recherche et filtres. Vos fichiers restent où ils sont, sauf demande contraire.

The Windows 11 problemLe problème Windows 11

On Windows 11 24H2 and later, most animated-wallpaper tools stop working. Here is why, and what this one does about it. Sur Windows 11 24H2 et suivants, la plupart des logiciels de fond d'écran animé cessent de fonctionner. Voici pourquoi, et ce que celui-ci y change.

What brokeCe qui a cassé

Windows changed how the desktop is composed: Progman now draws through DirectComposition and no longer has a DWM redirection surface. A window placed in the usual wallpaper layer is created, reports itself visible, sits in the right place — and is simply never drawn. Nothing fails loudly, the wallpaper just never appears. Windows a changé la composition du bureau : Progman dessine via DirectComposition et n'a plus de surface de redirection DWM. Une fenêtre placée dans la couche habituelle est créée, se déclare visible, occupe la bonne place — et n'est jamais dessinée. Rien n'échoue bruyamment, le fond n'apparaît simplement pas.

The fixLe correctif

One extended style: WS_EX_LAYERED, with an alpha of 255 so the window stays fully opaque. Layered windows take a different composition path inside DWM, one that still works — it is how Explorer draws the desktop icons themselves. The wallpaper goes back behind your icons, video included. Un style étendu : WS_EX_LAYERED, avec un alpha de 255 pour rester parfaitement opaque. Les fenêtres en couche empruntent un autre chemin de composition dans DWM, qui lui fonctionne encore — c'est ainsi que l'Explorateur dessine les icônes. Le fond repasse derrière vos icônes, vidéo comprise.

Check it yourselfVérifiez-le vous-même

The application ships a diagnostic that proves it on your machine: it shows a test pattern, briefly minimises your windows, captures the screen, restores everything, then reports whether the wallpaper was visible and whether your icons survived. L'application embarque un diagnostic qui le prouve sur votre machine : il affiche une mire, réduit brièvement vos fenêtres, capture l'écran, restaure tout, puis indique si le fond était visible et si vos icônes ont survécu.

InstallInstallation

  1. Download the installer with the button above. Téléchargez l'installateur avec le bouton plus haut.
  2. Run it. Windows will warn you that the application is not signed by a paid certificate: choose More info then Run anyway. Lancez-le. Windows affichera un avertissement, l'application n'étant pas signée par un certificat payant : choisissez Informations complémentaires puis Exécuter quand même.
  3. Pick your language on first launch, then import a wallpaper. That's it. Choisissez votre langue au premier lancement, puis importez un fond. C'est tout.
For video playbackPour la lecture vidéo

Install VLC 64-bit. Images and web wallpapers work without it. FFmpeg is optional and improves video thumbnails. Installez VLC 64 bits. Les images et les fonds web fonctionnent sans. FFmpeg est facultatif et améliore les vignettes vidéo.
